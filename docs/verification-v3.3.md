# Neon Drift 3.3 — Akina Mountain Rework

Выполнено: отдельное горное окружение Акины, гранёные скальные стены и гребни, лес, ущелья, отбойники с отражателями, предупреждающие щиты, двойная жёлтая разметка. Золотая плашка «РЕВОРК / ГОРНЫЙ ПЕРЕВАЛ» над карточкой трассы, горный силуэт в её схеме. Новая версия ресурсов 3.3.0.

Проверки:
- tests/akina.cjs: 4 проверки — свободные от дороги полные габариты декора, соседние шпильки, все секторы, одинаковые позиции при смене качества, ограниченный кэш окружения и очистка.
- tests/smoke.cjs: 31 проверка — проезд всех трасс, физика, отрисовка, сохранения, ресурсы, локальный сервер и звук. Для сетевой части запуск с разрешением на локальное соединение; все проверки завершились успешно.
- Браузер: золотая плашка на большом экране и при ширине 320px, настоящий заезд на S2000, верхние шпильки на высоком и низком качестве.
