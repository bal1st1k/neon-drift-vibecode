# Neon Drift 3.4.1 — фотографии целиком

Убрана фиксированная высота 310px и обрезка cover у фотографий AE86. Каждое изображение сохраняет исходные пропорции; галерея получила больше места и отдельное соотношение колонок для горизонтального и вертикального кадров Project D. На мобильном фотографии располагаются друг под другом.

Нажатие фотографии открывает просмотр во всё окно с contain: кадр целиком помещается в экран. Есть кнопка закрытия и Esc, фокус возвращается к фотографии. Просмотр использует существующие средства модальных окон и не меняет сохранение.

Пройдены 11 проверок tests/takumi.cjs и проверка синтаксиса app.js. В браузере проверены целая вертикальная фотография, увеличенная галерея, закрытие через Esc и просмотр при ширине 320px. Снимки: tests/proofs/takumi-photos-natural.png, takumi-photo-fullscreen.png, takumi-photo-mobile.png.
