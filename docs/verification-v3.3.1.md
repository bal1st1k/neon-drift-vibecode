# Neon Drift 3.3.1 — AE86 GT-APEX

Новый исходник пользователя скопирован без изменений из Downloads в for promt/car/SPRITE 2D/ae86-sprite.jpg и подключён в каталоге. Игровой PNG assets/cars/ae86-v2.png подготовлен существующим локальным конвертером: прозрачный фон, 260 × 142, перед автомобиля направлен вправо. Белые панели кузова и красные полосы сохранены. Отдельное имя PNG исключает использование прежнего файла из кэша. Конвертер теперь записывает результат по raceSprite из каталога.

Пройдены обе проверки tests/sprites.cjs: все 27 прозрачных PNG загружаются и рисуются при запрещённом чтении пикселей, игрок и соперники используют подготовленные спрайты с правильной ориентацией. В браузере проверены гараж и заезд на Акине. Снимки: tests/proofs/ae86-v2-garage.png, tests/proofs/ae86-v2-race.png.
